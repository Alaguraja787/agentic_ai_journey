## 🛠️ Projects

### Mini Agent v1.0

A simple AI agent built from scratch without LangChain, LangGraph, or other agent frameworks.

The agent will eventually follow this flow:

```text
User Request
     ↓
    LLM
     ↓
Choose Tool
     ↓
Execute Tool
     ↓
Tool Result
     ↓
    LLM
     ↓
Final Answer
```
